10 月这波华为的免费羊毛，值得单独记一篇。前面几篇一直在记免费模型，但基本都是"模型免费、工具自己搭"；华为这波不太一样，是**工具、模型、工具链打包一起送**。鸿蒙开发者从写码到 CI 全流程都能 0 元起步，挨个过一遍。

### DevEco Code：鸿蒙官方的终端 AI Agent

这是我现在写鸿蒙项目的主力工具。2026 年 6 月才首发（0.1.0），8 月底 stable 线就到 0.2.0，节奏很快。

![image-20261011102347089](/static/blog/image-20261011102347089.png)

<div style="font-size:0.8em; color:#606060; text-align: center; "> 图1 DEVECO 首页 </div>

它基于华为 BitFun 技术和开源 OpenCode，上手很熟悉：终端交互、Model / Provider / MCP / Skill 这些配置都还在，又集成了 HarmonyOS 精品 Skills、DevEco Studio 工具链和鸿蒙知识库，写码、构建、推包、修 ArkTS 报错、查文档，一条龙全在终端里搞定。

重点说免费的部分：

- **内置 GLM-5.1，登录华为账号就能用**，不用自己申请 API Key，单账号默认 50 次/分钟。之前在 OpenCode 里手填智谱 Key 踩过坑的（见 [GLM 7 天体验卡](/blog/ai/glm-7day)），这次直接跳过配置环节。
- UI 检查用内置的 Qwen3-VL 多模态模型，同样登录即用。它不在 `/models` 列表里，是 UI 检查子代理内部调的；要换第三方多模态只支持 Qwen 系列，配在 `deveco.jsonc` 的 `agent.ui_verification` 里。
- 也可以走 `/connect` 接第三方模型（ZhipuAI、Alibaba 等），`/models` 切换。

Agent 有 Build / Plan / Goal 三种模式，`/agents` 切换。日常小改动用 Build 直接干，大需求丢给 Goal，让它把"需求理解 → 代码生成 → 构建出包 → 推模拟器"整条链路自己跑完。

安装两条命令的事：

```bash
npm install -g @deveco/deveco-code
deveco
```

默认装的是 latest 尝鲜版，想稳就装 `@stable`，不过它比 latest 旧一个多月。升级用 `deveco upgrade`。环境要求 Windows 11 22H2+ 或 macOS 15+、Node 22+；装了 DevEco Studio 6.1+ 才能编译构建和推模拟器/真机，不装也能当普通 AI CLI 用，就是鸿蒙工程相关的活干不了。

### 码道 CodeArts 代码智能体：全家桶 + 每日免费积分

先把名字捋清楚：原"软件开发生产线 CodeArts"在 **2026 年 7 月 14 日更名"华为云码道 CodeArts"**，AI 编码产品叫"码道 CodeArts 代码智能体"。形态多到离谱：

- **IDE**：Windows / Mac / Linux ARM64，还有**鸿蒙 PC 版**（应用市场搜 CodeArts Agent 直接装）
- **VS Code / JetBrains 插件**：老 IDE 不换也能用
- **桌面端（Beta）**：一站式 AI 工作台，产品设计、数据分析、办公协同都往里塞
- **CLI/TUI**：不用开 IDE，终端里直接写码、改文件、解释代码、跑 Git、生成单测

免费力度：

- 官网挂着**"每日千万 Token 免费领"**的活动。
- 套餐分个人版/企业版，按积分计费，**个人版实测每天能领 1000 积分**，日常问答、小改动够用，具体数额以领取页为准。
- 鸿蒙特色是增训模型，拿华为海量研发数据训的，ArkTS 和鸿蒙 API 生成比通用模型准不少，配上鸿蒙专属 Agent、Skills，还有 Agent Team 专家团队打配合。
