### Token 三个月腰斩

```
Silicon Data（硅基流动） 的指数跌到 0.97 美元。
从 GPT-3.5 一路看到现在，70B 量化模型一张卡就能跑。
价格走势直接改变了很多人的付费习惯：
现在买 token 最多买一个月。周抛套餐要是有人出，我愿意吃一口螃蟹。
预付一年等于主动承担大半年的折价损耗。今天的价格就是三个月后的高价。
所有按量付费的额度，我都当 Perishable（易腐品）处理。
用完再充，绝不囤。

开学季最近很火热，各种送 Token，各种事情。
南大副教授蒋炎岩的新课《生成式软件工程》，
第一页 PPT 写着 “没有 Token 的 CS 学生应该立即退学” 。红字，上了微博热搜。
课程规则三条：
- 禁止古法编程
- Token 自费
- 不需要 token max xing（盲目堆 token）。

他的原话是“去 DeepSeek 充个一百块，好像还 OK”。
实在困难，还有 40 块的豆包兜底。做作业挑 Token 便宜的时间段。
他把 Token 叫 AI 时代的实验耗材，跟化学系的试剂一个待遇。

注意充值方式：一百块，现充现用，不办年卡。
这门课真正教的不是 vibe coding（氛围编程），是成本意识。
从今年秋天起是计算机学生的必修，对其他行业的人是选修，但价格战的走向跟每个人有关。
```

### 另一批买家，压根不看价目表

```
价格战最凶的时候，所有人都在比 API 单价。
但有一批买家从一开始就不看这张表。

政务、金融、军工、医疗。
核心诉求是数据不出域。
数据过云端，合规过不了，免费也不用。
他们买的是权重：模型参数本身，加上数据所有权。

全栈国产化 AI 工作站，鲲鹏 加 昇腾。
兼容 DeepSeek 和 Qwen，武汉政府已经在用。

算一笔账：
token 消耗过了临界点，本地部署单 token 成本是公有云的三分之一到五分之一。
这是采购部拿算盘打出来的，不是理论。这轮价格战影响的只是云端 API 定价层。

政企要不要上云，价格战说了不算。
对我们这种云端用户反而是好消息：
政企采购量托底了硬件和推理优化，云端单价只会继续掉。
```

### 价格战的反复，别把任何一家当长期承诺

```
DeepSeek 五月砸盘降价，八月反手涨价 4.5 倍，网友从“梁圣”到 “梁子”再改口到“牢梁”。

这种反复我也懵过，后来想通了：
先低价抢市场，再靠峰谷计费和订阅分层把利润找回来，定价策略而已。

单家涨价也没能拉住指数。
DeepSeek 八月涨上去的部分，被其他厂商的跟进降价摊平了。
整体曲线照旧往下走。
“跌一半”是行业性的成本下移，不是某一家的促销。

启示：别把任何一家的价格当长期承诺。
峰谷计费本身就是给高频用户的信号。错峰跑批处理，成本还能再砍。
蒋炎岩让学生挑便宜时间段做作业，说的是同一件事，
他管这叫实验耗材的使用规范。
```

### 没摸过桌面的语言模型，钱正流向物理世界

```
大模型读过人类对物理世界的所有描述，没摸过一次桌面。

智源 王仲远举过例子：
视频生成模型能生成一群在天上飞的猪。
物理世界不会这样运行。给机器人装一个分不清真实和虚幻的大脑，
它可能真觉得自己是钢铁侠。

今年世界机器人大会的共识是：
“小脑强于大脑”。运动控制进步快，理解真实世界普遍不行。

数据缺口是硬伤：
端到端能力要跃迁，至少需要千万小时级的第一视角视频。
现在的验证规模是 20 万小时，差两个数量级。

token 腰斩的今天，是语言模型最便宜的时点，也是它最悬浮的时点。
宇树把世界模型当最大投入方向。
无界动力下个月发新基座，
智源发了物理世界模型。
亏本卖语言 token 的钱，正在流向物理世界。
价格战收尾的地方，就是下一轮战争开幕的地方。
```

### 具体押哪条路线，行业没有共识。

```
至少四条在同时下注：
杨立昆（Meta 首席 AI 科学家）：在抽象空间里预测物理状态。
李飞飞（斯坦福教授）：机器先懂三维空间和几何。
主流厂商：VLA（视觉-语言-动作模型）。
阿里开源 Qwen Drive 4B VLA。

没有裁判。

前地平线副总裁说得很直白：今天没有一个路线是物理 AI 或 AGI 的终极路线，否则 L4 自动驾驶早就起来了。

语言模型主线倒出了个明确信号：
Qwen3.8-Max 八月初拿下代码生成榜全球第一。ELO 1668（对战评分，越高越强），比第二名高上百分。
更关键的是：旗舰闭源发布十天后，阿里把 2.4T 参数的 Max 级权重全量开源。
开源加工具链在具体任务上追平了闭源。白嫖免费权重的下限又抬高了一截。
```

### 我的用法：白嫖、月抛、本地

```javascript
降价的三分之二是推理成本真的降了。剩下三分之一，是各家把钱从一个战场搬到另一个战场。
免费是武器，不是慈善。但武器对准的是同行，捡便宜的是我们。

我现在的高频场景这么分配：
白嫖层：各家免费额度轮着用，不留忠诚度。
订阅层：固定需求包月，只买一个月，到期看价格再续。
// 本地层：数据敏感或高频批处理，70B 量化本地跑。

按量付费跑高频场景，大概率是买贵了。
价格还在跌，月抛是极限，周抛更好。当 Token 成为耗材，最好的理财就是不理财。

随用随充。
```
