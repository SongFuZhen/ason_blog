## 关于这个博客

你好，欢迎来到我的博客 👋

这个站点基于 [Skyplume](https://github.com/ruoduan-hub/next-blog-skyplume-template) 模板搭建，使用 **Next.js 15 App Router**、**TypeScript**、**Tailwind CSS 4** 与 **Contentlayer / MDX** 构建，默认以中文呈现。

> 做有用的东西，把它写下来，并不断改进这个系统。

我会在这里持续记录：

- 前端开发与工程实践
- 项目复盘与踩坑记录
- 一些关于工具与方法的思考

## 用 MDX 写作

文章使用 MDX 编写，可以在 Markdown 中直接使用 React 组件。下面是一个代码高亮的例子：

```ts
function greet(name: string) {
  return `你好，${name}！`
}

console.log(greet('世界'))
```

> 这是一条提示：文章配图请放在 `public/static/blog/<slug>` 目录下，并在 MDX 中引用。
