其实这本书我已经读过好几遍了。

里面举的例子，大多是国外的家庭、职场情境，搁在咱国内，未必处处对得上号。但架不住它戳人——它让我头一回开始反思：我平时那张嘴，到底是**怎么说话的？**也让我慢慢学着，换一种方式去跟人打交道。

之所以想写点东西唠唠这本书，说白了，是觉得周围好些人的说话方式和沟通，真不太让人舒服。

我从小在西北乡下长大。这地方大男子主义的风刮得猛，老父亲老母亲们都不善言辞，"爱"这个字，硬是憋在肚子里一辈子也说不出口。前二十年，我压根没意识到——说话，居然还是门技术活；话，还能这么有技巧地说。

好了，废话不多说。如果下面的字你读着有那么一点触动，那咱就当是 *一达 （一起）*来琢磨，与君共勉。

### **原来一直在用暴力沟通**

> 也许我们并不认为自己的谈话方式是暴力的，但我们的语言确实常常引发自己和他人的痛苦。

—— "你咋这么不中用"

—— "没俅本事"

—— "你犟啥犟"

打小，周围人就这么说话。听了几十年，早就习以为常，像空气一样不觉着有啥。听了二十多年，其实也没觉得有多疼——可这，就对了吗？

大伙儿都念叨"**语言暴力**、语言暴力"。可老辈子想不通：说话能有多暴力？说你两句还不行了？又没少你吃、没少你穿，也没动手打你，没让你少块肉、掉层皮。

话是这么讲。可有些话，像针，扎进去不流血，但淤青好多年散不掉，这个疙瘩是在心里的。

这样的沟通，本质是"评判"——先把你这个人给定了性，再去跟你说话。你接住的，不是信息，是**标签**。

### **说事实不说判断**

> 为了倾听他人，我们需要先放下已有的想法和判断，全心全意地体会对方。

这一节，是我翻得最勤的。因为每过一段时间的好日子，我就会得意忘形，开始高谈阔论起来。

书里把沟通拆成四步：**观察、感受、需要、请求**。头一步，就是"观察"——只说你眼睛看见的，别急着下结论。

难就难在，咱天生爱下判断。"地上扔着一双袜子"，这是观察；"你懒得跟猪一样"，这叫判断。可张口就来的，永远是后者。

先学会看，再学会听。听，比说难多了。咱乡下人，性子直，话赶话，谁也不服谁，谁也听不进谁。学着闭嘴，把嘴缝上，先把对方的话听完——这一步，我练了好久，现在也没及格。

放下自己那点想法和判断，去听对方到底在说啥、需要啥。这事儿，看着简单，做起来那可是真费劲。

### **不比吃，不比穿，你就比学习**

> 如果真的想过上悲惨生活，就去与他人做比较。

小时候最怕听见的一句话，是"你看人家谁谁谁"。

比吃，嫌你嘴馋；比穿，嫌你虚荣；好容易不比这些了，改比学习——"人家娃门门第一，你瞅瞅你"。这比吃比穿，伤得狠多了。

你把两个人往一块摁，分出个高下，被比下去的那个，接到的信号就是：你不如人，你不够努力，你还不够好。

80后爸妈那辈人，不晓得啥叫"非暴力沟通"，她们以为激将法能逼出个出息。可多少孩子，是被这一句句"你看人家"给比没了底气。长大以后，干啥都先觉得自己不配，先觉得自己差人一截。

**这两年有个挺有意思的变化。**

自打谷爱凌火了，越来越多的90后、00后像是忽然"觉醒"了过来，不再吃"别人家孩子"那一套压力。

你刷短视频，常能撞见这样的画面：别人家的孩子，在镜头里优雅地跳舞、行云流水地弹着钢琴。底下却总有一拨父母在叹气抱怨：你看看自家娃，整天就知道捧个手机，啥正事也不干。可往往话音未落，就有人回："人家那一节琴课多少钱、前前后后学了多少年，你先算算？"——比起拿自家娃去跟别人的成果比，倒有人先把人家的付出和年限，摊开比了比。

当我们用"应该""不得不"去要求自己和娃，那是在用内疚和羞耻当鞭子。比来比去，**比丢的是一个人的自我，得到的是一个人的自卑**。

### **我要我觉得，不要你觉得**

> 如果我们请求别人不做什么，对方也许感到困惑，不知道我们到底想要什么。

—— "你要听话来"

—— "我是为你好"

—— "你咋就不明白我的苦心"

这些话，熟不熟悉？

说起来，这节标题 "我要我觉得，不要你觉得"，本是**黄晓明**在一档综艺里随口说的话，当年一下子火遍全网、成了名梗。可笑着笑着就发现，它活脱脱就是好多关系里"我说了算"的写照。

书里有个扎心的区分：请求，和命令。你提请求，对方可以拒绝，你尊重；你下命令，对方不听就是"不孝""不懂事"。可仔细一琢磨，好些所谓的"为你好"，底下藏的都是"按我说的来"。

"我要我觉得，不要你觉得"——这八个字，是好多家庭、好多关系的病根。我们把**自个儿的期待，包装成对方的需要；把控制，包装成爱**。

而非暴力沟通这本教的是：先分清，这是我的需要，还是对方的需要。我可以表达我的期待，但我得接得住对方的"不"。接不住，那就不叫沟通，那叫驯服。

### **生气是自我伤害，吵架不是宽恕良药**

> 在生气时，批评和指责他人都无法真正传达我们的心声。直接说出我们的需要更有可能得到满足。

咱乡下汉子，脾气上来了，脖子一梗，嘴巴就跟刀子似的，说的话都是淬了毒的。

我们生气，根子不在别人，在自己。是咱自个儿的需要、期待落了空，咱却习惯把锅甩给对面那个人——"都是你气我"。

可真是人家气的吗？是人家的举动，撞上了你没被满足的需要。你把责任推过去，对方委屈，你也憋屈，俩人吵一架，谁也没宽恕谁，倒把旧账翻出新伤。

**生气，是拿别人的错，罚自个儿；吵架，是两头互相罚。**书里说，真正的宽恕，是先体会自己的感受，认下自己的需要，再去看对方。先爱自己，才谈得上爱别人。

我学了好些年，还是常上火。但至少现在，火上来那一秒，我会愣一下：我是真被气着了，还是我自己的需求没被满足，哪块儿没被疼着？

### **学会表达，不纠结**

> 别人的行为也许和我们的感受有关，但并不是感受的起因。感受根源于我们自身的需要。

这一点，是我最该补的课。

乡下长大的男娃，打小被教"男儿有泪不轻弹"，心里翻江倒海，嘴上一个字不吐。喜欢说不出口，委屈说不出口，想要啥，更说不出口——倒不是嘴笨，是底气不足、张不开嘴。开口要个东西，总觉得怪不好意思的，生怕人家觉得你贪得无厌、不知好歹。于是全指望对方"猜"——猜不着，就冷战，就委屈，就觉得"你根本不心疼我"。

可人家凭啥心疼你？你又不说。

非暴力沟通给了一套说法句式，笨是笨了点，但绝对管用：

> 当我看见______（观察），我感到______（感受），因为我需要______（需要），你愿不愿意______（请求）？

把"你根本不在乎我"，换成"我这阵子一个人吃饭，心里空落落的，我需要点陪伴，晚上咱一起吃个饭行不？"

**不纠结，不猜，不委屈自己，也不委屈对方。想要啥，好好说；不想要啥，也好好说。**

话出口的那一刻，心里的疙瘩，就松了一半。

### **好好说话实践手册**

下面这张表，是我照着书，把平时常听到的"暴力话"，换成"人话"。看看你中了几条：

| **平时爱说的（暴力沟通）**               | **改进的（非暴力沟通）**                         |
| ---------------------------------------- | ------------------------------------------------ |
| 光知道拿，不知道放，让我在你屁股后面收拾 | 把地上的袜子放到脏衣篮里                         |
| 你咋这么不中用                           | 这件事我来教你，咱慢慢来                         |
| 没俅本事                                 | 这方面你还可以再练练，有进步空间                 |
| 你犟啥犟                                 | 先听我把话说完，成不                             |
| 你看人家谁谁谁多争气                     | 我看到你这回数学进步了十分，我挺高兴             |
| 你就是懒                                 | 这周有三天没倒垃圾，我希望咱轮流来               |
| 我是为你好                               | 我担心你熬夜伤身体，能不能十二点前睡             |
| 你从来都不关心我                         | 这半个月咱没好好聊过天，我有点孤单，想跟你坐会儿 |
| 你怎么这么笨，这都做不好                 | 这个环节有点卡，我陪你一起捋一遍，能改好         |
| 这点小事都要问我，你自己没长脑子？       | 你先按想法出个初稿，拿不准的地方咱再碰           |
| 你这态度就是不行                         | 我注意到这次沟通有点急，咱们换个方式聊行不       |

| 你眼里还有这个家吗                       | 这周你忙，我心里有点空，周末咱一起过行不         |
| 你怎么老是这样                           | 这事已经好几次了，我有点难过，咱商量个办法       |
| 过不下去就离                             | 咱现在矛盾多，俩人都累，要不要找个时间好好谈谈   |

写完这些，我又把书翻回扉页。

说话这门艺术，不是读一本书就能学会的。它是日子，是一回回磕碰里，慢慢把嘴边的话，重新再学一遍。

### **写在最后**

说了这么多，最后想反过来问问你：

—— 你小时候，最常听见的那句"暴力话"是啥？它后来是怎么影响你的？

—— 有没有哪回，你明明是关心，话到嘴边却变成了指责？后来咋收的场？

—— 如果今晚就要用一次非暴力沟通，你最想跟谁说？那句最想说的话，是啥？

评论区唠唠呗。咱一起，把嘴边的话，慢慢学顺。

与君共勉。也跟我自个儿说一句：**慢点说，好好说。**
