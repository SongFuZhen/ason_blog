### 都有哪些工具

目前站点上已经有 50+ 个工具，大致分了这几类：

- **图片工具**：图片压缩、格式转换（JPG/PNG/WebP）、裁剪、EXIF 信息查看，还有一个专门处理华为应用市场图标和截图的小工具（上架过应用的同学懂的都懂）。
- **开发工具**：时间戳转换、Cron 表达式可视化编辑、UUID / GUID 生成、随机数生成，还有 GitHub Hosts 查询生成。
- **数据工具**：JSON 格式化 / 校验 / 精简、JSON 转 CSV、SQL 格式化，甚至可以在浏览器里直接跑 SQLite 查询（Playground）。
- **代码工具**：正则测试、正则生成（用自然语言描述生成正则）、Diff 对比、JSON Diff。
- **加密安全**：文本加密、MD5 / SHA-1 / SHA-256 哈希生成与对比、JWT 解码。
- **PDF 工具**：PDF 合并、拆分、转图片，还有一个专门给报销党的「发票合并」——多张发票 PDF 合并到一页纸上，支持多联排版。
- **格式转换**：Base64、URL 编解码、Markdown 预览 / 转 HTML、CSS 压缩美化、进制转换、字数统计。
- **设计与生成**：二维码生成、颜色格式转换（HEX/RGB/HSL）、调色板生成、Mock 数据生成（支持 JSON/CSV/SQL 导出）。
- **生活向**：房贷计算器（支持公积金 + 商贷组合贷款、利率变动、提前还款）、万年历（农历、节气、节假日调休）、离线中英翻译。
